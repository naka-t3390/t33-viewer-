背景と課題

#課題方針（承認済み）
①走行記録が増え、2段プルダウンでは選びにくい左サイドパネル式リスト（日付グループ＋セッションカード）
②ヘッドアップ時にタイルの文字が回転して読めないLeaflet → MapLibre GL JS 移行（文字常時正立）
③ページを開くたびに Google 同意画面サイレント再認証（初回のみ同意、以降は自動）

パスキー移行は不採用: Drive API へのアクセスには Google の OAuth アクセストークンが必須で、 パスキー（本人確認手段）では Drive の読み取り許可を発行できないため。

Phase 1: サイレント再認証（③）

現状の欠陥

js/auth.js の signIn() が再訪のたび prompt:"consent" でフル同意画面を出す。

設計

  • 許可済みフラグ: 初回ログイン成功時に localStorage["t33_auth_granted"]="1"。トークンや個人情報は保存しない。
  • 自動サイレント取得: 読み込み時にフラグがあれば requestAccessToken({prompt:""}) を自動実行。 成功→そのまま走行日リスト表示。失敗→従来のログインボタンにフォールバック。
  • 失効時の自動回復: Drive fetch が 401 → サイレント再取得を1回試し、成功なら同リクエスト再試行＋SWへ新トークン再送。 それでも失敗なら従来のエラー表示。

変更ファイル

js/auth.js・js/app.js・js/drive.js

テスト

純粋部分は node --test。完全検証は本番URLのみ可能（Googleセッション依存）→ デプロイ後にユーザー確認。

Phase 2: MapLibre GL JS 移行（②）

原因

OSM ラスタータイルは文字が画像に焼き込み済みで、CSS 回転では文字だけ正立できない。

設計

  • ライブラリ: MapLibre GL JS（CDN・ビルド不要）。Leaflet の CDN 参照を差し替え。
  • タイル: OpenFreeMap Liberty スタイル（無料・キー不要・商用可、日本語地名）。
  • 回転: map.setBearing(進行方位) ネイティブ機能で文字は常に正立。 対角線コンテナ・CSS回転・coverSquareSize などのハックは全撤去。
現行 (Leaflet)移行後 (MapLibre)
L.polyline(track)GeoJSON source + line layer（#2563c9・幅4）
L.circleMarker（自車）maplibregl.Marker（DOM円マーカー）
fitBounds(getBounds())map.fitBounds(LngLatBounds, {padding:24})
map-pane CSS 回転map.jumpTo({center:自車, zoom:17, bearing:方位})
L.control.scalemaplibregl.ScaleControl
ズーム +/-maplibregl.NavigationControl
  • ボタン群（全体を表示/進行方向を上）は現行の素DOM（.map-btns）方式を継続。
  • geo.js の headingAt 等は続投。coverSquareSize は関数・テストとも削除。
  • WebGL 必須（想定端末では問題なし）。sw.js・動画・グラフは不変。

テスト

node --test ＋ _verify_layout.html ハーネスを MapLibre に更新して実描画確認（文字正立を含む）。

Phase 3: セッションサイドパネル（①）

設計

  • レイアウト: 左 aside（パネル）＋右メインの2カラム。ヘッダーのボタンで開閉。 狭い画面（<760px）はオーバーレイ。#date/#session プルダウンは撤去。
  • 内容: 日付グループ（新しい順）→ セッションカード（時刻・動画有無・推定記録時間=セグメント数×10分）。選択中をハイライト。
  • 遅延読み込み: グループ展開時にその日のセッションを取得し Map<dateId, sessions> にキャッシュ。 初回は最新日を自動展開・先頭セッション自動選択（現行の初期挙動を維持）。
  • モジュール: DOM構築は新規 js/panel.js。純粋ロジック（sessionCardMeta）は js/parse.js に追加しテスト対象。

テスト

sessionCardMeta 等を node --test。ハーネスに複数セッションのモックを足して展開・選択・ハイライトを実描画確認。
